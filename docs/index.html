How a copy was judged

A copy is in use if a program has its working folder or an open file inside it, or its open chat was active in the last day and it has unsaved files or an open pull request. Active means its chat or its git history moved in the last 4 days. It is finished only when nothing in it exists only here (unsaved, untracked or ignored files, local-only commits, tags or reflog entries) and its work is on a remote. Anything unclear, and any check that failed, goes to your call. Removal checks each copy again, including the live remote.

How sure these numbers are

Counts and groups are exact for the moment of the scan. Sizes come from a folder-size count (1 GB = 1,024 MB): good for comparing copies, and an upper limit on space you get back, because copies of the same project can share storage, so removing one may free less than its listed size. Free space is what the system reported at scan time, on its own scale (macOS counts 1 GB as 1,000 MB, about 7% apart). “Finished” rests on cached remote evidence and is checked live before any removal.
